Suffix & Prefix কমপ্লিট মাস্টার গাইড

একাডেমিক পরীক্ষা (SSC & HSC) ও প্রতিযোগিতামূলক প্রস্তুতি: সমস্ত রুলস, প্রিফিক্স, সাফিক্স ও ১০০টি টেস্ট প্র্যাকটিস

📖 অধ্যায় ১: মূল ধারণা ও শব্দ গঠন (Basic Concepts)

১. Root / Base Word (মূল শব্দ)

যে মূল শব্দটিকে আর কোনো ক্ষুদ্র অংশে ভাঙা যায় না এবং যার একটি সম্পূর্ণ স্বাধীন অর্থ থাকে, তাকে Root Word বা Base Word বলে।

উদাহরণ: Happy, Read, Act, Friend ইত্যাদি।

২. Affix (শব্দাংশ)

যেসব বর্ণ বা বর্ণ সমষ্টি মূল শব্দের পূর্বে বা পরে যুক্ত হয়ে নতুন শব্দ ও পার্টস অফ স্পিচ তৈরি করে, তাদের Affix বলে। Affix প্রধানত দুই প্রকার:

  • Prefix (উপসর্গ): মূল শব্দের পূর্বে বসে নতুন শব্দ তৈরি করে। (যেমন: Un + happy = Unhappy)
  • Suffix (প্রত্যয়): মূল শব্দের শেষে বসে নতুন শব্দ গঠন করে। (যেমন: Kind + ness = Kindness)

📖 অধ্যায় ২: সমস্ত Prefix (উপসর্গ)-এর বিস্তারিত তালিকা ও নিয়ম

বিপরীতার্থক, অবস্থান ও রূপান্তরকারী সকল Prefix

Prefixব্যবহারের নিয়মউদাহরণ (Base → New)বাংলা অর্থ
Un-সাধারণ বিপরীত বা অভাব অর্থেHappy → Unhappy, Wise → Unwiseঅসুখী, নির্বোধ
Dis-অনাস্থা, বিপরীত বা দূরীকরণ অর্থেHonest → Dishonest, Agree → Disagreeঅসৎ, অমত করা
Im-সাধারণত P, M, B দিয়ে শুরু শব্দের পূর্বেPossible → Impossible, Mortal → Immortalঅসম্ভব, অমর
In-সাধারণ বিপরীত অর্থেComplete → Incomplete, Correct → Incorrectঅসম্পূর্ণ, ভুল

Ir-'R' দিয়ে শুরু শব্দের পূর্বেRegular → Irregular, Responsible → Irresponsibleঅনিয়মিত, দায়িত্বজ্ঞানহীন

Co-সহযোগী বা একসাথে কাজ করা অর্থেOperation → Cooperation, Worker → Coworkerসহযোগিতা, সহকর্মী
Inter-পারস্পরিক বা মধ্যে অর্থেNational → International, Net → Internetআন্তর্জাতিক, ইন্টারনেট
Sub-অধীন বা নিচে অর্থেMarine → Submarine, Way → Subwayপানিতে ডুবোজাহাজ, পাতালপথ

Over-অতিরিক্ত বা মাত্রাতিরিক্ত অর্থেLoad → Overload, Eat → Overeatঅতিরিক্ত বোঝা, বেশি খাওয়া
Under-কম বা নিচে অর্থেEstimate → Underestimate, Value → Undervalueকম মূল্যায়ন করা
Re-পুনরায় বা আবার করা অর্থেWrite → Rewrite, Build → Rebuildপুনরায় লেখা, পুনর্নির্মাণ
Pre-পূর্ববর্তী বা আগে অর্থেPaid → Prepaid, Caution → Precautionপূর্ব পরিশোধিত, সতর্কতা
Post-পরবর্তী অর্থেWar → Postwar, Graduate → Postgraduateযুদ্ধোত্তর, স্নাতকোত্তর

📖 অধ্যায় ৩: সমস্ত Suffix (প্রত্যয়)-এর মাস্টার তালিকা

Noun, Adjective, Verb ও Adverb গঠনের সুনির্দিষ্ট Suffix সমূহ

Suffixনিয়ম ও কাজউদাহরণবাংলা অর্থ

-nessগুণ বা বৈশিষ্ট্য প্রকাশKind → Kindness, Dark → Darknessদয়া, অন্ধকার
-ity / -tyঅবস্থা বা গুণ প্রকাশPure → Purity, Active → Activityবিশুদ্ধতা, কর্মতৎপরতা
-er / -orব্যক্তি বা যন্ত্রবাচক nounTeach → Teacher, Create → Creatorশিক্ষক, সৃষ্টিকর্তা
-ance / -enceঅবস্থা বা ভাব প্রকাশImportant → Importance, Differ → Differenceগুরুত্ব, পার্থক্য
-domক্ষেত্র বা অবস্থা প্রকাশFree → Freedom, Wise → Wisdomস্বাধীনতা, প্রজ্ঞা
-shipসম্পর্ক বা পদবী প্রকাশFriend → Friendship, Member → Membershipবন্ধুত্ব, সদস্যপদ
-hoodপর্যায় বা দশা প্রকাশChild → Childhood, Neighbor → Neighborhoodশৈশব, প্রতিবেশী এলাকা

-able / -ibleযোগ্য বা সক্ষম অর্থেRead → Readable, Access → Accessibleপাঠযোগ্য, প্রবেশগম্য
-iveপ্রবণতা অর্থেAct → Active, Create → Creativeসক্রিয়, সৃজনশীল

-yযুক্ত বা ভাবাপন্ন অর্থেHealth → Healthy, Salt → Saltyস্বাস্থ্যকর, লোনাবিযুক্ত
-ic / -icalবৈশিষ্ট্যসূচক অর্থেScience → Scientific, History → Historicalবৈজ্ঞানিক, ঐতিহাসিক

📖 অধ্যায় ৪: বাক্যে Parts of Speech চেনার অবস্থানগত নিয়ম (Position Rules)

সঠিক শব্দ বসানোর সুনির্দিষ্ট কৌশল

  • Noun এর অবস্থান: Sentences এর Subject বা Object এর স্থানে, Preposition-এর পরে, এবং Determiner (a, an, the, this, my, some) এর ঠিক পরে Noun বসে।
    যেমন: I need your cooperation.
  • Adjective এর অবস্থান: Noun এর ঠিক পূর্বে Adjective বসে অথবা Linking Verb (am, is, are, was, were, look, feel, seem, become) এর পরে Adjective বসে।
    যেমন: She is an intelligent girl.
  • Verb এর অবস্থান: Subject এর ঠিক পরে মূল Verb বসে কিংবা Modal Auxiliary (can, could, shall, should, will, would, must) এর পর Verb এর Base form বসে।
    যেমন: We should obey our parents.
  • Adverb এর অবস্থান: Adverb সাধারণত Verb, Adjective বা অন্য কোনো Adverb কে modify করে। অনেক সময় বাক্যের শুরুতে কমার পূর্বে বসে পুরো বাক্যকে modify করে।
    যেমন: Fortunately, he survived the crash.

📖 অধ্যায় ৫: বানানের গুরুত্বপূর্ণ পরিবর্তন ও নিয়ম (Spelling Rules)

Suffix যুক্ত করার সময় বানান পরিবর্তনের ৩টি প্রধান নিয়ম

  • Rule 1 (y পরিবর্তন): Base word-এর শেষে যদি 'y' থাকে এবং তার আগে Consonant থাকে, তবে Suffix যোগ করার সময় 'y' উঠে গিয়ে 'i' হয় (তবে -ing যোগ করার সময় y ওঠে না)।
    উদাহরণ: Happy + ness = Happiness | Cry + ed = Cried (কিন্তু Cry + ing = Crying)।
  • Rule 2 (Silent 'e' লোপ): কোনো শব্দের শেষে নীরব বা Silent 'e' থাকলে এবং তার পরে Vowel দিয়ে শুরু হওয়া কোনো Suffix (-ed, -ing, -able, -er) যুক্ত হলে সেই 'e' সাধারণত বাদ যায়।
    উদাহরণ: Write + er = Writer | Care + ful = Careful (এখানে Consonant দিয়ে শুরু হওয়ায় e অপরিবর্তিত থাকে)।
  • Rule 3 (Consonant Double): Monosyllabic (এক সিলেবল বিশিষ্ট) শব্দে যদি শেষে একটি মাত্র Vowel এবং তার পরে একটি মাত্র Consonant থাকে, তবে Suffix যোগ করলে শেষের Consonant টি দ্বিত্ব (Double) হয়।
    উদাহরণ: Run + er = Runner | Big + est = Biggest।
