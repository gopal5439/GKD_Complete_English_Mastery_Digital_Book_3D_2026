Chapter 01 • Fundamental Concept

Tense ও Time-এর মৌলিক পার্থক্য

VS

Tense অর্থ "কাল" / সময়।

এই কাল ৩টি— অতীত কাল (Past Tense), বর্তমান কাল (Present Tense), ভবিষ্যৎ কাল (Future Tense)।

সময় ও কাল দুটো একই মনে হলেও আসলে দুটো এক জিনিস নয়।

সময় (Time) Specific Moment

সময়: কোন একটি নির্দিষ্ট মুহূর্ত।
যেমন— এখন সময় 10:45 বাজে।
একটু পর 11:00 বাজবে। এটা হলো সময়।

10:45 (মুহূর্ত ১)
নির্দিষ্ট বিন্দু
11:00 (মুহূর্ত ২)
VS
কাল (Tense) Time Span / Interval

কিন্তু, এই 10:45–11:00 পর্যন্ত পুরো সময়ের ব্যবধানই হচ্ছে কাল।
তেমনি অতীত, বর্তমান ও ভবিষ্যৎ এই ৩টি মূলত প্রধান কাল।

10:45 ← সময়ের ব্যবধান (১৫ মিনিট) = কাল → 11:00
অতীত (Past)
বর্তমান (Present)
ভবিষ্যৎ (Future)
Chapter 02 • The 4 Aspects

এই যেকোনো কালেই ৪ ধরনের ঘটনা ঘটতে পারে—

১ ঐ সময়ে সাধারণ / স্বাভাবিক ঘটনা। (Indefinite)
V1 / V2 / V5
২ ঐ সময়ে অনির্দিষ্ট সময় ধরে চলমান ঘটনা। (Continuous)
MV(ing) তেছি, তেছ, তেছেন, চ্ছ, চ্ছি, চ্ছেন
৩ ঐ সময়ে নির্দিষ্ট সময় ধরে চলমান ঘটনা। (Perfect Continuous)
MV(ing) + since/for + time
৪ ঐ সময়ে ঘটনা ঘটেছে / ঘটানো হবে / ২টি ঘটনা এমন। (Perfect)
V3

তাই প্রত্যেকটি Tense-এ ৪টি করে ঘটনা মিলে Tense মোট 3 × 4 = 12 প্রকার।

তবে মাথায় রাখবে, এই ৪টি হলো ঐ সময়ের ঘটে যাওয়া ঘটনা। মূলত তা Tense নয়।

Chapter 04 • Master Formula Chart

একনজরে ১২টি Tense-এর গঠন ও সংক্ষিপ্ত কৌশল

Sub, Obj, Ext বারবার মুখস্থ করার প্রয়োজন নেই। কেবল পরিবর্তিত Verb-গুলো মনে রাখুন—

মূল কাল (Tense) ঘটনা (Aspect) গঠন প্রণালী (Structure)
Present Indefinite : Sub + V1 / V5 + Obj + Ext.  (Helping Verb- do, does)
Continuous : Sub + am / is / are + V(ing) + Obj + Ext.
Perfect : Sub + have / has + V3 + Obj + Ext.
Perfect Continuous : Sub + have/has been + V(ing) + Obj + Ext + Since/for + time.
Past Indefinite : Sub + V2 + Obj + Ext.  (Helping Verb- did)
Continuous : Sub + was / were + V(ing) + Obj + Ext.
Perfect : Sub + had + V3 + Obj + Ext.
Perfect Continuous : Sub + had been + V(ing) + Obj + Ext + Since/for + time.
Future Indefinite : Sub + shall/will + V1 + Obj + Ext.
Continuous : Sub + shall/will be + V(ing) + Obj + Ext.
Perfect : Sub + shall/will have + V3 + Obj + Ext.
Perfect Continuous : Sub + shall/will have been + V(ing) + Obj + Ext + Since/for + time.

সংক্ষিপ্ত ও কৌশলী সূত্র—

1. Indefinite
  • Present Indefinite : V1 / V5 (Helping Verb- do, does)
  • Past Indefinite : V2 (Helping Verb- did)
  • Future Indefinite : V1 (Future মানেই Shall/will / ব, বে, বেন sound)
2. Continuous মানেই "চলমান", তেছি/তেছ/তেছেন/চ্ছ/চ্ছি/চ্ছেন..... V(ing)
  • Present Continuous : am / is / are
  • Past Continuous : was / were
  • Future Continuous : be (shall/will be)
3. Perfect মানেই V3
  • Present Perfect : have / has
  • Past Perfect : had
  • Future Perfect : have (shall/will have)
4. Perfect Continuous মানেই Perfect-এর HV-এর সাথে "been" যুক্ত।
  • Present P. Cont. : been (have/has been)
  • Past P. Cont. : been (had been)
  • Future P. Cont. : been (shall/will have been)
